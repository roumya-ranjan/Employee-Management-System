# Employee Management System

A web application for managing employee records, built with **Spring Boot**, **JSP** and **Oracle Database**. It supports the four basic CRUD operations: create, read, update and delete.

---

## Features

| Operation | Description | Status |
|-----------|-------------|--------|
| **Create** | Add a new employee using a registration form | Done |
| **Read** | View all employees in a sorted report table | Done |
| **Update** | Edit an existing employee's details | In progress |
| **Delete** | Remove an employee record with a confirmation prompt | In progress |

Other highlights:
- Home page with a link to the employee report
- Report page listing all employees with **Edit** and **Delete** actions
- Registration form with a department dropdown (10, 20, 30)
- Auto-generated employee numbers using an Oracle sequence
- Friendly "No Data" message when the table is empty

## Database

The application uses the `emp` table:

| Column | Type | Description |
|--------|------|-------------|
| `EMPNO` | NUMBER | Primary key, generated by sequence `emp_seq` |
| `ENAME` | VARCHAR2(30) | Employee name |
| `JOB` | VARCHAR2(20) | Job title |
| `SAL` | NUMBER | Salary |
| `DEPTNO` | NUMBER | Department number (10, 20 or 30) |

Create the sequence if it does not exist:

```sql
CREATE SEQUENCE emp_seq START WITH 1000 INCREMENT BY 1;
```

## Getting Started

### Prerequisites
- JDK 17 or later
- Maven
- Apache Tomcat 11
- Oracle Database with a pluggable database available
- Lombok installed in your IDE

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Employee-Management-System.git
   ```
2. Open `src/main/resources/application.properties` and set your database details:
   ```properties
   spring.datasource.url=jdbc:oracle:thin:@localhost:1521/ORCLPDB
   spring.datasource.username=YOUR_USER
   spring.datasource.password=YOUR_PASSWORD
   spring.datasource.driver-class-name=oracle.jdbc.OracleDriver

   spring.jpa.hibernate.ddl-auto=none
   spring.jpa.show-sql=true

   spring.mvc.view.prefix=/WEB-INF/pages/
   spring.mvc.view.suffix=.jsp
   ```
3. Build the project:
   ```bash
   mvn clean install
   ```
4. Deploy to Tomcat 11 and open:
   ```
   http://localhost:8080/Employee-Management-System/
   ```

## Application URLs

| URL | Method | Purpose |
|-----|--------|---------|
| `/` | GET | Home page |
| `/show_report` | GET | Employee report |
| `/register` | GET | Show the registration form |
| `/register` | POST | Save a new employee |
| `/edit?no={empno}` | GET | Edit an employee |
| `/delete?no={empno}` | GET | Delete an employee |
